# Full audit: bugs and completeness (2026-10-28, at `04e9d07`)

Seven parallel read-only audits covered the whole codebase: back-end storage core, back-end features and API, editor, whiteboard, views and properties, shell (calendar, tasks, palette and the rest), and completeness against the spec and plans. Every bug below was reproduced, by a scratch script or test on fixture copies, unless it is marked *(code reading)*. Nothing was fixed yet. Fix them one per commit with a regression test, as `CONTINUE.md` says.

## Fix first (data loss, security, or the app breaking)

1. **The local API accepts any Origin and any Host.**
   - **Cross-site writes:** a "simple" `text/plain` POST from any web page writes files through `/api/attachments` and `/api/images` (201 for `evil.exe`, `x.html`).
   - **DNS rebinding:** there is no Host check, so a rebinding page can read the whole space and call `POST /api/spaces/delete` with `permanent`.
   - **Where:** `server.py:617`, and the fixed port in `__main__.py:31`.
   - **Fix:** allow only the `127.0.0.1` and `localhost` hosts, reject a foreign `Origin` on writes, and require `application/octet-stream` or a custom header on uploads.
2. **A rename can stop halfway.** A multi-line plain YAML scalar holding a link makes `replace_in_value` raise `FrontmatterError`. `_rewrite_other` doesn't catch it, so the file has already moved but later referrers keep the old link. (`space.py:1523-1541`, `frontmatter.py:411-469`)
3. **U+2028, U+2029 or NEL in a frontmatter value deletes other keys.** `_lines` uses `str.splitlines`. For example, the title `"Line sep"` followed by one save silently deletes `createdAt`. (`frontmatter.py:202-206`)
4. **A case-only move in `change_type` overwrites another file.** With `Pages/Alpha.md` and `Pages/alpha.md`, changing the type replaces Alpha, and it doesn't go to the trash. `whiteboardtrash._move_one` has the same pattern. (`space.py:1916-1956`, `2338-2345`)
5. **A title starting with `.` makes the object vanish.** It becomes a dotfile and drops out of the index. Attachments named `.env` are stored but never listed. (`space.py:193-216` `safe_filename`)
6. **A failure partway through `trash_type` strands the type and its templates** in the trash with no manifest, so they can't be restored. Write the manifest first. (`space.py:2957-3021`)
7. **Editor: dragging a block merges paragraphs.** For `A\n\nB\n\nC`, dragging C to the top saves `C\nA…`, which reloads as one paragraph. (`handles/dragMove.ts:42` with `preserve.ts` `serializeWithPreservation`)
8. **Editor: edits typed during an in-flight save are lost** when you switch objects or close the tab. The queued re-flush exits early or runs after the editor is destroyed. (`editor/useAutosave.ts:85-129`)
9. **Editor: a code block containing ```` ``` ```` is corrupted on save.** It always fences with exactly three backticks.
10. **Editor: line-start Markdown in plain text isn't escaped.** `# x`, `- x`, `1. x`, `---` and `$b$` turn into other blocks on reload. The trigger can be paste, `disableNumberedListTransformation`, or text such as `2024. was good`.
11. **Whiteboard: a failed save retries with no delay.** A 500 gave 1,000 PUTs in under 600 ms, and the tab can run out of memory. (`whiteboard/useBoard.ts:102-107`, `:150`)
12. **Whiteboard: failed ink saves are dropped silently.** The pending strokes are cleared, nothing retries and no toast shows. Strokes drawn before the ink file loads are never saved. (`whiteboard/ink/useInkDoc.ts:79-82`, `:104-106`, `:143`)
13. **Kanban: dragging a card with a multi-value property replaces every value.** Labels `[A, C]` dragged to B become `[B]`. The same code serves tags, collections and relations. (`views/group.ts:465-470` `valueForGroup`)
14. **Table and kanban: a second edit to the same row is lost.** Both writes carry the version from render time, so the second gets a 409, "Changed elsewhere. Reloaded.", and is dropped. (`views/table/TableLayout.tsx:239`, `KanbanLayout.tsx:120`)
15. **A property key shared by two types resolves to the wrong type's definition.** Grouping, calculations and filter validity all go through `findDef`, which picks the first type in the space with that key. Kanban columns then show the other type's options, and drops write options this type doesn't have. (`views/filter.ts:184`, `group.ts:302`, `calc.ts:162`)
16. **One out-of-range reminder stops every reminder in the space.**
    - **Cause:** `remind: 99999999 days before`, or a date of `9999-12-31`, raises in `tick`. (`reminders.py:162`, `:168`, `:278`)
    - **Related:** the same dates make `GET /api/calendar` return 500 for every range. (`calendarquery.py:318`, `localtime._os_offset_at`)
17. **Editing a task just after its reminder time cancels the reminder.** `due()` drops a trigger when `trig <= lastUpdated`. (`reminders.py:281`)

## Back end: other bugs

- **Renaming retargets other objects' links.** Renaming Alpha to "Notes" makes an existing `[[Notes]]` resolve to the renamed object. (`space.py:2013-2103`)
- **Frontmatter link rewrite on rename is wrong for some YAML forms.**
  - An unquoted `owner: [[X]]` or a plain multi-line value stays stale.
  - A block-list mapping item `- role: '[[X]]'` turns into a string.
  - Multi-line single-quoted values and double-quoted escapes change.
- **Long non-ASCII names fail with `ENAMETOOLONG`.** Filenames are capped in characters rather than bytes, and the temp name adds about 14 bytes. Creating "é"×130 fails, and saving an existing 249-byte name fails every time. (`textfile.py:118-136`, `safe_filename`)
- **Mixed line endings:** a single CRLF line makes every new line CRLF. Use the majority ending. (`textfile.py:33-40`)
- **An upload named `x.md` becomes an object,** which is then unlisted and refused by `/api/file`. (`server.py:1493`, `media.py:337`)
- **The `/api/tasks/*` routes answer 500 on bad paths** (`../x.md`, `""`, NUL) because they don't catch `ValueError`. (`api_tasks.py:108`, `:520`)
- **More malformed input gives 500s:** `/api/file?path=a%00b.md`, and `PUT /api/types/{id}` with `propertyDefinitions: 1`.
- **The watcher stays silent** when an external edit restores exactly the content of an earlier app write, because `own_writes` is never cleared. (`watcher.py`)
- *Unconfirmed:*
  - Windows reserved names (`con`, `aux`, `nul`) as type or collection ids.
  - CJK-only names all get the slug `type`.
  - A corrupt `spaces.json` is overwritten.
  - `JsonStore.write` and `spaceconfig.patch` don't re-check the file before replacing it.

## Editor: other bugs

- **Deleting the first item of a numbered list** renumbers it on reload: `1,2,3` with the first deleted saves `2. b`, so the list now starts at 2. (`preserve.ts` `preserveList`)
- **Edits that only add trailing whitespace or a hard break are dropped** by `trimEnd` comparison. This covers indentation inside a code block and Shift-Enter in a paragraph. (`preserve.ts` `preserveLines`, `blockKeysEqual`)
- **Turning a multi-line block into a heading** splits it into a heading and a paragraph on reload.
- **A heading ending in ` #` loses the `#`,** because CommonMark reads it as a closing sequence.
- **Paragraphs with a bare URL, an `<autolink>` or `&nbsp;`** load as raw monospace blocks. This is very common content. (`document.ts:203-212` `contentKey`)
- **Any line containing `::` makes the whole block raw:** `std::vector` does it, and a whole list or table goes raw. (`document.ts:154` `FIELD_LINE`)
- **Reference links `[a][r]` and footnote refs `[^1]`** are escaped into plain text on any edit.
- **Minor drift:** lazy blockquote lines get `> `, a continuation indent after a backslash break is lost, and a caption with `-->` becomes `-- >`.

## Whiteboard: other bugs

- **Dragging two or more frames moves their contents once per frame.** (`store.ts:356-366`)
- **Alt-drag duplicate of a frame:** the copy follows the original. (`store.ts:331-341`)
- **Separate resize gestures merge into one undo step,** because the key is never sealed. (`store.ts:351`)
- **The "Nothing in this view" overlay ignores ink and swallows pointer events,** so you can't draw, marquee-select or pan in empty space. (`WhiteboardCanvas.tsx:1043-1056`)
- **Ctrl+D on a selected Line or Arrow does nothing.** (`actions.ts:558-590`)
- **Auto-sized blocks are treated as 420×60** in frame wrapping, containment and snapping. (`actions.ts:82-98` `nodeBox`)
- *Unconfirmed:*
  - Strokes over the server's 20,000-point cap make every later ink save fail.
  - Ink undo is reset by unrelated board changes.
  - A board open in a page and a peek misses its own events (shared `CLIENT_ID`).
  - Palm-first then pen is ignored, and there is no `lostpointercapture` handler.

## Views and properties: other bugs

- **The Time zone setting only affects display.** Typing a date, the time input, filter and group day boundaries, and `ctx.now` all use the device zone. In Tokyo-vs-New-York testing, typing "today at 9:00" stores and shows 10:00 PM. (`DatePicker.tsx:136,262`, `views/dates.ts`, `group.ts dateBucket`, `filter.ts matchDate`)
- **Focusing and leaving a number cell writes without an edit:** 1/3 as a percentage becomes 0.333…2999, and 1e-21 becomes 0. (`NumberCell.tsx:62-67`)
- **Percentage entry stores floating-point noise:** typing 14.3 shows "14.300000000000002%". (`NumberCell.tsx:43`)
- **"By Range" grouping with fractional steps** misplaces values and shows noisy labels. (`group.ts:281-286`)
- **A number filter with no value yet** hides every row. (`filter.ts:244-247`)
- **The date field can't parse its own display text,** for example "Oct 30, 2026, 2:00 PM", or the DMY and MDY formats. (`DatePicker.tsx:116`)
- **Hiding or moving a column changes which columns are pinned,** because the pin is an index into the visible columns. (`tableConfig.ts:118,125`) *(code reading)*
- **A format with decimals min > max** throws inside render and takes down the view. (`format.ts:58-62`)
- **Number input accepts the wrong things:** "Infinity" and "0x10" are accepted, and "50%" is ignored. (`format.ts:111`)
- *Unconfirmed:*
  - Currency negatives show "$-5".
  - Percentage filters compare against the raw fraction.
  - Filter rows are keyed by index.
  - Sorting by a relation uses the raw link text.
