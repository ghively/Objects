# Projects

A **Project** has a status, a timeframe and the people involved. It comes with "Start with basic setup"; its objects live in `Projects/`.

## Create one

Press **New** (Ctrl+U) and pick **Project**, or right-click **Projects** in the sidebar and choose **Create Project**. Name it, set its status and timeframe, and describe it in the body.

## Properties

- **Status**: Planned, In Progress, On Hold or Completed.
- **Type**: Work or Personal.
- **Timeframe**: when it starts and ends (a date range).
- **Collaborators**: the people working on it.
- **Organizations** and **Meetings**: links to who it is for and the meetings about it.
- **Cover image** and **Notes** (the body).

A project is also a piece of work, so it carries the same work fields as a task: **Steps**, Blocked on, Findings, Confidence and the ticket fields (Ticket ID, System, Desk status and so on). Leave them empty if you don't need them.

## Tips

- Give a task a **Project** to file it under that project.
- The Tasks dashboard's **Projects map** (under More views, Plan) shows each project as a line: its steps, then its tasks, with the percent done and the next step.
